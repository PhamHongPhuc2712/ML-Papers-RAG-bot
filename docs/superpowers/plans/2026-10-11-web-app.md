# Web App (M4, revised): Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Next.js web app where anyone can search the corpus and open a paper, and a
signed-in user can chat with the corpus — answers whose every claim shows the passages it
cites — and come back to earlier chats.

**Architecture:** Next.js App Router in `frontend/`. The browser only ever talks to the Next
server: `/api/session` signs in and keeps the access token in an `httpOnly` cookie, and
`/api/v1/[...path]` forwards API calls to the backend with that token, streaming chat events
through unchanged. Types come from `frontend/openapi.json`, the backend's published contract.
Pages: `/` (search), `/papers/[id]`, `/login`, `/chat`, `/chat/[id]`. Browser tests run against
a small scripted backend so they need no GPU, database or money; one recorded walkthrough runs
against the real local stack.

**What this plan replaces.** Old M3's P3.4 (the research workspace with feed, library and
settings pages) and old M4's P4.3–P4.4 (chat and upload UI). The pages it drops — `/feed`,
`/library`, `/settings`, uploads — are out of scope since 2026-10-11.

**Tech Stack:** Node.js 22, `next@16.3.6`, `react@19.3.0`, `react-dom@19.3.0`,
`typescript@6.0.3` (strict), `eslint@9.39.5` with `eslint-config-next@16.3.6`,
`vitest@5.0.2`, `@playwright/test@1.63.0`, `@axe-core/playwright@4.13.0`,
`openapi-typescript@7.13.0`, `@types/node@22.20.4`, `@types/react@19.3.0`,
`@types/react-dom@19.3.0`. Each is the newest stable release at least two weeks old on
2026-10-11 (npm publish dates checked that day); ESLint stays on 9 because
`eslint-config-next` 16's React plugins predate ESLint 10. No CSS framework and no component
library: plain CSS with design tokens.

**Spec:** [Technical specification](../specs/2026-09-05-ml-research-copilot-design.md), revised
2026-10-11: §10 (API, pages, states, accessibility). Depends on the
[chat backend plan](2026-10-11-chat-backend.md) through C6 (the endpoints and `openapi.json`).

**Status:** Draft for review, 2026-10-11. Starts after C6.

## Global Constraints

- Node.js 22; TypeScript `strict` with `noUncheckedIndexedAccess`; `package-lock.json`
  committed; `npm ci` only in CI; exact versions in `package.json`.
- **The access token never reaches browser JavaScript.** It lives in the `copilot_session`
  cookie (`httpOnly`, `SameSite=Lax`, `Path=/`, `Secure` when `SESSION_COOKIE_SECURE=true`).
  The proxy refuses `/api/v1/auth/*`, so no page can obtain a token through it.
- The Next server reads `BACKEND_URL` (default `http://127.0.0.1:8000`) and nothing else from
  the backend's configuration. No secret is bundled into client code.
- Every state the spec names has a visible, announced rendering: loading, empty, expired
  session, degraded search, insufficient evidence, spend cap reached, failed turn.
- Accessibility is acceptance: labelled inputs, visible focus, keyboard-only use of every
  page, status changes in `aria-live` regions, and no `serious` or `critical` axe violation.
- `frontend/lib/api-types.ts` is generated from `frontend/openapi.json` and never edited by
  hand; CI fails when they differ.
- ORB text never appears in fixtures, screenshots or tests (fixtures here are invented).
- Commit trailer: `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **A session expires while a page is open.** Expected: the next API call returns 401; the
   proxy clears the cookie; the page goes to `/login?expired=1&next=<where you were>` and says
   the session expired; signing in returns there. Pinned in W1 and W3.
2. **The answer budget runs out.** Expected: the chat shows "Today's answer budget is used up.
   It resets at 00:00 UTC." with no retry button, keeps the user's message, and the composer
   stays usable. Pinned in W3.
3. **The user navigates away mid-answer or presses send twice.** Expected: leaving aborts the
   stream (the backend marks the turn interrupted); the send button is disabled while a turn
   runs, so one click is one request id; a retry after a retryable error reuses that request
   id. Pinned in W3.
4. **Degraded or empty search.** Expected: a degraded ordering shows a banner naming it as
   possibly incomplete; no results says so and suggests broadening; the API being down shows
   a retryable error, not a blank page. Pinned in W2.
5. **A long answer or long passage text.** Expected: passages wrap and scroll inside the
   evidence panel; the 2,000-character composer limit is shown as a counter and enforced
   before sending. Pinned in W3.

`frontend/lib/sse.ts`:
```ts
export type SseEvent = { event: string; data: unknown };

/** One `event:`/`data:` block; `data` is JSON, as the chat endpoint sends it. */
export function parseBlock(block: string): SseEvent | null {
  let event = "message";
  const data: string[] = [];
  for (const line of block.split("\n")) {
    if (line.startsWith("event:")) event = line.slice(6).trim();
    else if (line.startsWith("data:")) data.push(line.slice(5).replace(/^ /, ""));
  }
  if (data.length === 0) return null;
  return { event, data: JSON.parse(data.join("\n")) };
}

/** Events from a `text/event-stream` body, as they arrive; frames end with a blank line. */
export async function* readEvents(body: ReadableStream<Uint8Array>): AsyncGenerator<SseEvent> {
  const reader = body.getReader();
  const decoder = new TextDecoder();
  let buffer = "";
  try {
    for (;;) {
      const { value, done } = await reader.read();
      buffer += decoder.decode(value ?? new Uint8Array(), { stream: !done });
      let boundary = buffer.indexOf("\n\n");
      while (boundary !== -1) {
        const parsed = parseBlock(buffer.slice(0, boundary));
        buffer = buffer.slice(boundary + 2);
        if (parsed) yield parsed;
        boundary = buffer.indexOf("\n\n");
      }
      if (done) return;
    }
  } finally {
    reader.releaseLock();
  }
}
```

```ts
export class ApiError extends Error {
  constructor(
    readonly status: number,
    readonly body: ApiErrorBody,
  ) {
    super(body.message);
  }
}

export async function errorFrom(response: Response): Promise<ApiError> {
  const payload = (await response.json().catch(() => null)) as { error?: ApiErrorBody } | null;
  return new ApiError(
    response.status,
    payload?.error ?? {
      code: `http_${response.status}`,
      message: "The request failed.",
      retryable: response.status >= 500,
    },
  );
}

async function call<T>(path: string, init?: RequestInit): Promise<T> {
  const response = await fetch(`/api/v1/${path}`, {
    ...init,
    headers: { "content-type": "application/json", ...init?.headers },
    cache: "no-store",
  });
  if (!response.ok) throw await errorFrom(response);
  if (response.status === 204) return undefined as T;
  return (await response.json()) as T;
}

  search: (request: SearchRequest) =>

  deleteChat: (id: string) => call<void>(`chats/${encodeURIComponent(id)}`, { method: "DELETE" }),
```

```ts
import { cookies } from "next/headers";
import { SESSION_COOKIE, backendUrl, cookieSecure } from "@/lib/server";

export const runtime = "nodejs";
export const dynamic = "force-dynamic";

const unreachable = {
  error: { code: "backend_unreachable", message: "The service is not reachable.", retryable: true },
};

export async function POST(request: Request): Promise<Response> {
  const body = (await request.json().catch(() => null)) as { email?: unknown; password?: unknown } | null;
  if (typeof body?.email !== "string" || typeof body.password !== "string") {
    return Response.json(
      { error: { code: "validation_error", message: "Email and password are required.", retryable: false } },
      { status: 422 },
    );
  }
  let upstream: Response;
  try {
    upstream = await fetch(`${backendUrl()}/v1/auth/token`, {
      method: "POST",
      headers: { "content-type": "application/json" },
      body: JSON.stringify({ email: body.email, password: body.password }),
      cache: "no-store",
    });
  } catch {
    return Response.json(unreachable, { status: 503 });
  }
  const payload = (await upstream.json().catch(() => null)) as
    | { access_token?: string; expires_in?: number }
    | null;
  if (!upstream.ok || !payload?.access_token) {
    return Response.json(payload ?? unreachable, { status: upstream.ok ? 502 : upstream.status });
  }
  (await cookies()).set(SESSION_COOKIE, payload.access_token, {
    httpOnly: true,
    sameSite: "lax",
    secure: cookieSecure(),
    path: "/",
    maxAge: payload.expires_in ?? 3600,
  });
  return Response.json({ ok: true });
}

export async function DELETE(): Promise<Response> {
  (await cookies()).delete(SESSION_COOKIE);
  return new Response(null, { status: 204 });
}
```

`frontend/app/api/v1/[...path]/route.ts`:
```ts
import { cookies } from "next/headers";
import { SESSION_COOKIE, backendUrl } from "@/lib/server";

export const runtime = "nodejs";
export const dynamic = "force-dynamic";

type Context = { params: Promise<{ path: string[] }> };

const REQUEST_HEADERS = ["content-type", "accept"];
const RESPONSE_HEADERS = ["content-type", "cache-control"];

function failure(status: number, code: string, message: string, retryable: boolean): Response {
  return Response.json({ error: { code, message, retryable } }, { status });
}

async function forward(request: Request, { params }: Context): Promise<Response> {
  const { path } = await params;
  // Tokens are issued only to /api/session, which keeps them out of page scripts.
  if (path[0] === "auth") return failure(404, "not_found", "No such endpoint.", false);
  const search = new URL(request.url).search;
  const target = `${backendUrl()}/v1/${path.map(encodeURIComponent).join("/")}${search}`;
  const headers = new Headers();
  for (const name of REQUEST_HEADERS) {
    const value = request.headers.get(name);
    if (value) headers.set(name, value);
  }
  const jar = await cookies();
  const token = jar.get(SESSION_COOKIE)?.value;
  if (token) headers.set("authorization", `Bearer ${token}`);
  const init: RequestInit = { method: request.method, headers, cache: "no-store", redirect: "manual" };
  if (request.method !== "GET" && request.method !== "HEAD") init.body = await request.text();
  let upstream: Response;
  try {
    upstream = await fetch(target, init);
  } catch {
    return failure(503, "backend_unreachable", "The service is not reachable.", true);
  }
  const out = new Headers();
  for (const name of RESPONSE_HEADERS) {
    const value = upstream.headers.get(name);
    if (value) out.set(name, value);
  }
  if (upstream.status === 401 && token) jar.delete(SESSION_COOKIE);
  // The body streams through unchanged: chat events arrive as the backend sends them.
  return new Response(upstream.body, { status: upstream.status, headers: out });
}

export const GET = forward;
export const POST = forward;
export const DELETE = forward;
```

```tsx
export function LoginForm({ next }: { next: string }) {
  const router = useRouter();
  const [error, setError] = useState<string | null>(null);
  const [busy, setBusy] = useState(false);

  async function submit(event: FormEvent<HTMLFormElement>) {
    event.preventDefault();
    const form = new FormData(event.currentTarget);
    setBusy(true);
    setError(null);
    const response = await fetch("/api/session", {

      router.replace(next);
      router.refresh();
      return;
    }
    setError(
      response?.status === 401
        ? "Email or password is incorrect."
        : "The service is not reachable. Try again in a moment.",
    );
  }

  return (
    <form onSubmit={submit} aria-describedby={error ? "login-error" : undefined}>
      <p>
        <label htmlFor="email">Email</label>
        <input id="email" name="email" type="email" autoComplete="username" required />
      </p>
      <p>
        <label htmlFor="password">Password</label>

      </p>

          {error}
        </p>
      ) : null}
```

```js
      .map(({ id, title, created_at, updated_at }) => ({ id, title, created_at, updated_at }));
    return json(res, 200, { request_id: randomUUID(), items });

  }

}).listen(PORT, "127.0.0.1");
```

```tsx
import { usePathname, useRouter, useSearchParams } from "next/navigation";
import { useCallback, useEffect, useState, type FormEvent } from "react";
import { ApiError, api, type SearchResponse } from "@/lib/api";
import { PaperCard } from "./PaperCard";

const FILTERS = { year_from: null, year_to: null, venues: [], fulltext_only: false };

export function SearchView() {
  const router = useRouter();
  const pathname = usePathname();
  const params = useSearchParams();
  const query = params.get("q") ?? "";
  const [draft, setDraft] = useState(query);
  const [pages, setPages] = useState<SearchResponse[]>([]);
  const [busy, setBusy] = useState(false);
  const [error, setError] = useState<string | null>(null);

  const run = useCallback(async (text: string, cursor: string | null) => {
    setBusy(true);
    setError(null);
    try {
      const page = await api.search({ query: text, mode: "hybrid_rerank", filters: FILTERS, limit: 20, cursor });
      setPages((previous) => (cursor ? [...previous, page] : [page]));
    } catch (failure) {
      setError(failure instanceof ApiError ? failure.body.message : "Search is not reachable. Try again.");
    } finally {
      setBusy(false);
    }
  }, []);

  useEffect(() => {
    setDraft(query);
    if (query) void run(query, null);
    else setPages([]);
  }, [query, run]);

  function submit(event: FormEvent<HTMLFormElement>) {
    event.preventDefault();
    const text = draft.trim();
    if (text) router.push(`${pathname}?q=${encodeURIComponent(text)}`);
  }

  const last = pages.at(-1);
  const degraded = pages.some((page) => page.degraded);
  const items = pages.flatMap((page) => page.items.map((item) => ({ item, paper: page.papers[item.paper_id] })));

  return (
    <section aria-busy={busy}>
      <form role="search" onSubmit={submit} style={{ display: "flex", gap: 8 }}>
        <label htmlFor="q" className="visually-hidden">
          Search papers
        </label>
        <input id="q" value={draft} maxLength={2000} onChange={(e) => setDraft(e.target.value)} placeholder="e.g. contrastive learning for sentence embeddings" />
        <button className="primary" type="submit" disabled={busy}>
          Search
        </button>
      </form>
      <div role="status" aria-live="polite">
        {degraded ? (
          <p className="banner warn">These results may be incomplete: part of the search ran out of time ({last?.warnings.join(", ")}).</p>
        ) : null}
        {busy && !items.length ? <p className="muted">Searching…</p> : null}
      </div>
      {error ? (
        <p className="banner error" role="alert">
          {error} <button type="button" onClick={() => void run(query, null)}>Retry</button>
        </p>
      ) : null}
      {query && !busy && !error && pages.length > 0 && items.length === 0 ? (
        <p>No papers matched. Try fewer or broader words.</p>
      ) : null}
      {items.map(({ item, paper }) => (paper ? <PaperCard key={item.paper_id} paperId={item.paper_id} paper={paper} /> : null))}
      {last?.next_cursor ? (
        <button type="button" disabled={busy} onClick={() => void run(query, last.next_cursor ?? null)}>
          More results
        </button>
      ) : null}
    </section>
  );
}
```

```tsx
type Props = { params: Promise<{ id: string }> };

async function load<T>(path: string): Promise<T | null> {
  const response = await fetch(`${backendUrl()}${path}`, { cache: "no-store" });
  if (response.status === 404 || response.status === 422) return null;
  if (!response.ok) throw new Error(`paper request failed: ${response.status}`);

}

export default async function PaperPage({ params }: Props) {
```

```ts
  condensing: "Reading your follow-up…",

};

export const INSUFFICIENT =
  "The indexed papers don't contain enough evidence to answer this. Try naming a paper or method, or ask more specifically.";

/** Evidence ids numbered in the order the answer first cites them. */
export function citationNumbers(message: ChatMessage): Map<string, number> {
  const numbers = new Map<string, number>();
  for (const claim of message.claims ?? []) {
    for (const id of claim.evidence_ids) if (!numbers.has(id)) numbers.set(id, numbers.size + 1);
  }
  return numbers;
}
```

```tsx
function where(item: StoredEvidence): string {
  if (item.page_start == null) return item.section;

    : `pp. ${item.page_start}–${item.page_end}`;
```

```tsx
"use client";

import { usePathname, useRouter } from "next/navigation";
import { useEffect, useRef, useState, type FormEvent, type KeyboardEvent } from "react";
import { ApiError, api, errorFrom, loginRedirect, streamTurn, type ApiErrorBody, type ChatMessage } from "@/lib/api";
import { STAGES } from "@/lib/chat-labels";
import { readEvents } from "@/lib/sse";
import { Answer } from "./Answer";
import { EvidencePanel } from "./EvidencePanel";

const LIMIT = 2000;
type Failure = ApiErrorBody & { requestId: string; message_text: string };

export function ChatView({ chatId, about }: { chatId: string | null; about: string | null }) {
  const router = useRouter();
  const pathname = usePathname();
  const [id, setId] = useState<string | null>(chatId);
  const [messages, setMessages] = useState<ChatMessage[]>([]);
  const [draft, setDraft] = useState(about ? "In this paper, " : "");
  const [stage, setStage] = useState<string | null>(null);
  const [failure, setFailure] = useState<Failure | null>(null);
  const [focus, setFocus] = useState<{ message: string; evidence: string } | null>(null);
  const abort = useRef<AbortController | null>(null);

  function expired() {
    router.replace(loginRedirect(pathname, true));
  }

  useEffect(() => {
    if (!chatId) return;
    api.chat(chatId).then(
      (detail) => setMessages(detail.messages),
      (error: unknown) => {
        if (error instanceof ApiError && error.status === 401) expired();
        else if (error instanceof ApiError && error.status === 404) router.replace("/chat");
      },
    );
    return () => abort.current?.abort();
    // eslint-disable-next-line react-hooks/exhaustive-deps
  }, [chatId]);

  async function send(text: string, requestId: string) {
    setFailure(null);
    setStage("searching");
    const controller = new AbortController();
    abort.current = controller;
    const optimistic: ChatMessage = {
      id: requestId, ordinal: messages.length, role: "user", status: "complete", text,
      claims: [], evidence: [], standalone_query: null, warnings: [], error_code: null,
      corpus_release_id: null, created_at: new Date().toISOString(),
    };
    setMessages((previous) => (previous.some((m) => m.id === requestId) ? previous : [...previous, optimistic]));
    try {
      const response = await streamTurn({ request_id: requestId, chat_id: id, message: text }, controller.signal);
      if (!response.ok || !response.body) {
        const error = await errorFrom(response);
        if (error.status === 401) return expired();
        throw error;
      }
      for await (const event of readEvents(response.body)) {
        const data = event.data as Record<string, unknown>;
        if (event.event === "chat" && typeof data.chat_id === "string" && !id) {
          setId(data.chat_id);
          window.history.replaceState(null, "", `/chat/${data.chat_id}`);
          window.dispatchEvent(new Event("chats-changed"));
        } else if (event.event === "status" && typeof data.stage === "string") {
          setStage(data.stage);
        } else if (event.event === "final") {
          setMessages((previous) => [...previous, data as unknown as ChatMessage]);
          window.dispatchEvent(new Event("chats-changed"));
        } else if (event.event === "error") {
          const body = (data as { error: ApiErrorBody }).error;
          setFailure({ ...body, requestId, message_text: text });
        }
      }
    } catch (error) {
      if (controller.signal.aborted) return;
      const body = error instanceof ApiError ? error.body : { code: "network_error", message: "The connection dropped. Try again.", retryable: true };
      setFailure({ ...body, requestId, message_text: text });
    } finally {
      setStage(null);
      abort.current = null;
    }
  }

  function submit(event?: FormEvent) {
    event?.preventDefault();
    const text = draft.trim();
    if (!text || text.length > LIMIT || stage) return;
    setDraft("");
    void send(text, crypto.randomUUID());
  }

  function onKey(event: KeyboardEvent<HTMLTextAreaElement>) {
    if (event.key === "Enter" && !event.shiftKey) {
      event.preventDefault();
      submit();
    }
  }

  const running = stage !== null;
  return (
    <div style={{ display: "grid", gap: 16 }}>
      <ol aria-label="Conversation" style={{ listStyle: "none", padding: 0, display: "grid", gap: 12 }}>
        {messages.map((message) =>
          message.role === "user" ? (
            <li key={message.id}><p style={{ margin: 0, fontWeight: 600 }}>{message.text}</p></li>
          ) : message.status === "complete" || message.status === "insufficient" ? (
            <li key={message.id}>
              <Answer message={message} onCite={(evidence) => setFocus({ message: message.id, evidence })} />
              {focus?.message === message.id ? <EvidencePanel message={message} focused={focus.evidence} /> : null}
            </li>
          ) : (
            <li key={message.id} className="muted">This answer was not completed ({message.error_code ?? message.status}).</li>
          ),
        )}
      </ol>
      <div role="status" aria-live="polite">{stage ? <p className="muted">{STAGES[stage] ?? "Working…"}</p> : null}</div>
      {failure ? (
        <div role="alert" className="banner error">
          {failure.message}{" "}
          {failure.retryable ? (
            <button type="button" onClick={() => void send(failure.message_text, failure.requestId)}>Retry</button>
          ) : null}
        </div>
      ) : null}
      <form onSubmit={submit}>
        <label htmlFor="composer">Ask about ML papers</label>
        <textarea id="composer" rows={3} value={draft} onChange={(e) => setDraft(e.target.value)} onKeyDown={onKey}
          aria-describedby="composer-count" />
        <p id="composer-count" className="muted" style={{ margin: "4px 0" }}>{draft.length} / {LIMIT}</p>
        <button className="primary" type="submit" disabled={running || !draft.trim() || draft.length > LIMIT}>Send</button>
      </form>
    </div>
  );
}
```
The `Retry` resends the same `requestId` and text, so the backend re-runs that turn rather
than starting another (C2's rule for failed and interrupted turns).

```tsx
  useEffect(() => {
    load();
    window.addEventListener("chats-changed", load);
    return () => window.removeEventListener("chats-changed", load);
  }, [load]);

  async function remove(id: string, title: string) {
    if (!window.confirm(`Delete “${title}”? This cannot be undone.`)) return;
    await api.deleteChat(id);
    if (window.location.pathname === `/chat/${id}`) router.replace("/chat");
    load();
  }

  return (
    <nav aria-label="Chats" style={{ borderRight: "1px solid var(--border)", paddingRight: 12 }}>
      <p><Link href="/chat">New chat</Link></p>
      <ul style={{ listStyle: "none", padding: 0 }}>
        {chats.map((chat) => (
          <li key={chat.id} style={{ display: "flex", gap: 4, alignItems: "center" }}>
            <Link href={`/chat/${chat.id}`} aria-current={pathname === `/chat/${chat.id}` ? "page" : undefined} style={{ flex: 1 }}>
              {chat.title}
            </Link>
            <button type="button" aria-label={`Delete chat ${chat.title}`} onClick={() => void remove(chat.id, chat.title)}>×</button>
          </li>
        ))}
      </ul>
    </nav>
  );
}
```

```ts
// Run by hand against the real local stack (REAL_STACK=1). It signs in with REAL_EMAIL and
// REAL_PASSWORD, asks two turns about a paper in our corpus, and saves screenshots. It spends
// about $0.01 on the hosted model and needs an idle GPU.
import { expect, test } from "@playwright/test";

test("search, a paper, and a two-turn chat on the real stack", async ({ page }) => {
  test.setTimeout(180_000);
  await page.goto("/?q=contrastive+learning+of+sentence+embeddings");
  await expect(page.getByRole("article").first()).toBeVisible({ timeout: 30_000 });
  await page.screenshot({ path: "test-results/real-search.png", fullPage: true });
  await page.getByRole("article").first().getByRole("link").first().click();
  await expect(page.getByRole("heading", { level: 1 })).toBeVisible();
  await page.goto("/login?next=%2Fchat");
  await page.getByLabel("Email").fill(process.env.REAL_EMAIL ?? "");
  await page.getByLabel("Password").fill(process.env.REAL_PASSWORD ?? "");
  await page.getByRole("button", { name: "Sign in" }).click();
  await page.waitForURL("**/chat");
  const box = page.getByLabel("Ask about ML papers");
  await box.fill("What loss does SimCSE use to train sentence embeddings?");
  await box.press("Enter");
  await expect(page.getByRole("article", { name: "Answer" })).toHaveCount(1, { timeout: 90_000 });
  await box.fill("How large was its batch size?");
  await box.press("Enter");
  await expect(page.getByRole("article", { name: "Answer" })).toHaveCount(2, { timeout: 90_000 });
  await page.getByRole("article", { name: "Answer" }).last().getByRole("button").first().click();
  await page.screenshot({ path: "test-results/real-chat.png", fullPage: true });
});
```
